# radial-piston-hydraulic-pump
Mechanical Design and CAD Modeling | École Centrale de Lille

Project Overview

This project focuses on the design and development of a radial piston hydraulic pump intended for integration into a vertical-axis wind turbine.

The objective was to design a hydraulic system capable of converting the mechanical energy generated by the wind turbine into hydraulic energy, allowing power to be transmitted to the base of the structure, where a hydraulic motor drives an electrical generator.

The project was developed as part of the engineering curriculum at École Centrale de Lille, France.

Project Objectives

Analyze the technical requirements of the hydraulic system.

Perform engineering calculations for pump sizing.

Select an appropriate mechanical architecture.

Design and model mechanical components using CAD software.

Develop the complete mechanical assembly.

Evaluate the integration of the pump into the wind turbine system.

Engineering Design Process

1. Requirements Analysis and Sizing

The first stage involved analyzing the system requirements and performing the engineering calculations necessary to define the main characteristics of the hydraulic pump.

2. Mechanical Design

A radial piston configuration was selected, and the mechanical architecture was developed considering the system's functional requirements.

3. CAD Modeling and Assembly

The pump components were modeled using Onshape, followed by the development of the complete mechanical assembly.

4. Technical Report

An engineering design report was prepared, presenting the calculations, design methodology, technical decisions, and results obtained
